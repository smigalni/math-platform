# Specialist role briefs

These files define bounded responsibilities for specialist reviews. They are delegation contracts, not executable agent configurations.

- `content-author.md`: produces and revises textbook material.
- `mathematics-reviewer.md`: challenges mathematical correctness and verifies solutions.
- `pedagogy-reviewer.md`: checks curriculum fit and learning design.
- `technical-qa.md`: checks build, links, rendering and presentation.

When the runtime supports subagents, delegate independent tasks with the relevant brief and a precise artifact/scope. Require evidence and a structured report. When subagents are unavailable, apply the briefs as separate review passes and disclose that they were not independent agents.
