# Bidragsveiledning

Prosjektet åpnes for flere bidragsytere når kjernesystemet er testet og stabilt. Inntil da fungerer dette dokumentet som foreløpig arbeidsstandard.

## Før du starter

- Les README, AI_WORKFLOW og relevante standarder.
- Finn ut om oppgaven gjelder felles plattform eller en bestemt bok.
- Undersøk eksisterende løsning før du oppretter nye mønstre.

## Når du lager innhold

- Følg pedagogiske og visuelle standarder.
- Kontroller matematikk og fasit.
- Ikke legg til vanskelighetsmerking eller ekstra bokser uten pedagogisk grunn.

## Når du endrer kode eller konfigurasjon

- Bruk en egen branch.
- Hold endringen avgrenset.
- Kjør relevante kontroller.
- Beskriv hva som er testet i pull request.

## Pull request

En pull request skal forklare:
- Hva som er endret.
- Hvorfor endringen er nødvendig.
- Hvilke sider eller komponenter som påvirkes.
- Hvilke tester og visuelle kontroller som er utført.
- Eventuelle kjente begrensninger.
