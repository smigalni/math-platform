# Visjon

## Hvorfor plattformen finnes

Vi skal utvikle digitale matematikklærebøker som gjør matematikk lettere å forstå, øve på og undervise i. Plattformen skal gjøre det mulig å lage flere bøker uten å måtte finne opp struktur, design, kvalitetssikring og arbeidsflyt på nytt hver gang.

## Mål

1. Utvikle minst tre lærebøker som kan brukes med ekte elever.
2. Bygge felles tekniske og pedagogiske standarder som kan gjenbrukes.
3. Bruke AI som en aktiv utviklingspartner, men med tydelige krav til kontroll og kvalitet.
4. Gjøre prosjektet forståelig for andre lærere og utviklere som senere kan bidra.
5. Forbedre bøkene gjennom faktisk undervisning og elevtilbakemeldinger.

## Hva plattformen ikke skal være

Plattformen skal ikke eie eller blande sammen faginnholdet i bøkene. Den skal heller ikke tvinge alle bøker inn i identisk pedagogisk struktur når fag eller elevgrupper krever ulike løsninger.
